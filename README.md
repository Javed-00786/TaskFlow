# 🚀 TaskFlow

## Full-Stack AI-Assisted Task Management Platform

TaskFlow is a full-stack task and project management platform designed to help users organize projects, create and manage tasks, track priorities, monitor progress, and work through a clean and intuitive web dashboard.

The platform also includes an AI-assisted **Quick Add** feature that parses plain-English task descriptions into structured task records.

## ✨ Features

### 📋 Task Management

- Create tasks
- Edit tasks
- Delete tasks
- Search tasks by title
- Add task descriptions
- Set task priority
- Set due dates
- Track task status
- Assign tasks to projects

### 📁 Project Management

- Create projects
- View available projects
- Select projects from a dropdown
- Assign tasks to projects
- Filter tasks by project
- Manage multiple projects

### 🤖 AI Quick Add

TaskFlow provides an AI-assisted **Quick Add** feature that converts natural-language descriptions into structured task information.

**Example input:**

text
Finish the report next Friday, it's urgent
